# Moorhuhn Jagd

Ein Moorhuhn-artiges Schießspiel im Browser — eine einzelne HTML-Datei, keine
Abhängigkeiten, keine Installation.

## Spielen

`index.html` im Browser öffnen. Fertig.

## Spielprinzip

90 Sekunden Zeit, so viele Hühner wie möglich abschießen.

| Aktion | Steuerung |
| --- | --- |
| Zielen | Maus bewegen (oder tippen auf Touch) |
| Schießen | Linksklick / Leertaste |
| Nachladen | `R` oder Rechtsklick |
| Pause | `P` |
| Ton an/aus | `M` |

## Punkte

- **Braunes Huhn** — 100 Punkte
- **Blaues Huhn** — 200 Punkte, deutlich schneller
- **Goldenes Huhn** — 500 Punkte, braucht zwei Treffer, gibt +3 Sekunden
- **Entfernungsbonus** — weit entfernte (kleine) Hühner bringen bis zu 2,5× Punkte
- **Combo** — Treffer in Folge steigern den Multiplikator bis x2
- **Fehlschuss** — −10 Punkte
- **Schild getroffen** — −150 Punkte

Das Magazin fasst 8 Schuss; Nachladen dauert gut eine Sekunde. Der Rekord wird
lokal im Browser gespeichert.
